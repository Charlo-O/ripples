# 纸上涟漪

一张可以写字的水面纸笺。输入文字时泛起涟漪，支持七种背景（六种纸色和竹简）、印章和音效。

- 落墨先淡而散、随后收紧；删掉的字在水面上淡开散去；涟漪的轻重与音效的重音同拍。
- 换纸像翻书：旧纸从左上角卷起，沿对角线翻过去离开，露出底下的新纸，水面随之起波纹、滴水。
- 「换一张纸」不翻页，而是把新纸直接铺上去：新纸从右下角扑进来，着水的那条线一路推向左上角，最后一角落平。线上挤出水纹，偶尔有气泡困在纸下、被慢慢推出去；刚铺上的湿纸会透出底下旧字的淡影，随后隐去。
- 纸离开水面时各有质感：宣纸、皮纸带毛边，瓷青纸裁边齐整；薄纸透字多，厚纸卷得更圆；洒金笺弯折时金箔闪光。
- 页边的标题和按钮随纸而动：新纸到哪里，哪里的字就换成新纸的颜色；有纸从标题上方经过时，标题暂时让开。
- 竹简上文字竖排，从右往左，一简一行，写在两道编绳之间；卷动时旧简保留竖排、新纸已是横排。
- 竹简不翻页，而是卷起：换走竹简时，它从左边卷成一束滚出右侧，露出底下的纸；换成竹简时，一束竹简从右侧滚进来摊开；竹简上「换一张纸」时，新简从右侧滚进来，直接铺在旧简上。卷动时竹片相碰作响，水面留下一道道波纹。
- 点按印章盖在原处，拖到纸上即留下落款。
- 系统开启「减少动态效果」时，以上过渡退化为淡入淡出。

在线使用：<https://charlo.cn/ripples/>

GitHub Pages 入口：<https://charlo-o.github.io/ripples/>（继承账号已有的 `charlo.cn` 域名，会跳转到该域名）。

## 本地运行

在项目目录运行：

```sh
python -m http.server 8000
```

打开 <http://localhost:8000>。无需安装依赖或构建。

## 发布

GitHub Pages 从 `main` 分支根目录发布。推送更新后，GitHub 会自动重新部署。
`.nojekyll` 用于直接发布静态文件。

## 文件

- `index.html`：页面与样式。
- `app.js`：WebGL 涟漪、文字编辑、纸张和音效交互。
- `sfx.js`：内嵌音效数据；文件注释标注来源为 CC0 Freesound 素材。
- `fonts/HuiwenMincho.ttf`：汇文明朝体。
- `tools/prep_sfx.py`：从原始音频生成音效数据，需要另外准备原始素材和 FFmpeg；使用网页时无需运行。

页面默认文字引用朱熹《观书有感》。纸色与音效偏好保存在当前浏览器；输入的文字不会上传到服务器。
